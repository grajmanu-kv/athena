## Your extraction task

For each atomic claim in the LLM response:

1. **Atomicity** — one claim = one independently evaluable proposition.
   Split compound propositions. "X is high because Y failed" →
   claim 1: factual (X is high) + claim 2: causal (Y caused X).

2. **claim_type** — assign exactly one:
   - `factual`: asserts a current/historical state of the world
   - `causal`: asserts A caused B (requires ≥1 assumption — the mechanism)
   - `predictive`: asserts a future state (requires time_horizon)
   - `normative`: asserts what should be done

3. **epistemic_modality** — assign exactly one:
   - `asserted`: stated as fact, no qualification
   - `hedged`: qualified with uncertainty language (likely, probably, appears)
   - `speculative`: exploratory, no factual anchor (could be, perhaps, might)
   - `hypothetical`: conditional on unstated premise (if X were true, then Y)

4. **source_span** — copy the **verbatim** fragment from the LLM response.
   Must appear word-for-word in the original. Do not paraphrase.

5. **proposition** — restate the claim in plain unambiguous language.
   Replace pronouns with referents. Use declared term definitions.
   Remove hedging language (capture it in confidence_language instead).

6. **assumptions** — required non-empty for `causal` claims.
   Document the proposed mechanism. What must be true for this
   causal relationship to hold?

7. **time_horizon** — required for `predictive` claims.
   `raw`: verbatim time reference. `normalized`: ISO 8601 if parseable
   (PT15M, PT2H, PT30S), otherwise null.

8. **conditions** — explicit conditions under which the claim holds.
   Also use to flag: boundary violations, constraint violations,
   terminological drift, undeclared term ambiguity.

9. **scope** — domain + temporal + spatial scope as specific as possible.
   Format: "[entity/location], [time reference]"

10. **confidence_language** — verbatim confidence marker if present
    (likely, certainly, may, it is clear that). Null if none.

Return claims in the order they appear in the response.
Return an empty list if the response contains no extractable claims.

Do NOT extract:
- Restatements of information from the prompt (context, not claims)
- Meta-commentary ("I will now analyse...")
- Greetings, acknowledgements, formatting text
- Direct quotes from the prompt
