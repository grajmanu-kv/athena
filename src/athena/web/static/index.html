Paste a query and the response it produced, set the risk context, and run.

Athena splits the response into atomic claims, checks each against structural rules, your constraints and boundaries, and any known facts, then issues one verdict for the whole response.

Running the pipeline…

decompose → extract → classify → guards → assess → resolve → decide. This makes several model calls; expect 10–60 s.

The verdict and per-claim states are Athena's own output. “Verified” means consistent with the facts you supplied, not true in the world. Claim extraction and guard judgements are made by an LLM and can be wrong; read the rationale, not just the label.
